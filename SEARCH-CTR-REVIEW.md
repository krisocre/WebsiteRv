## Measurement plan

1. Save the current Search Console export and record each release date. Use Web search with the country filter set to Canada. Establish separate Desktop and Mobile baselines. Keep the unfiltered view for evaluating the overall 4–5% CTR objective.
2. Use URL Inspection to confirm Google fetched the updated canonical pages. Check representative result titles and snippets on desktop and mobile for the priority queries and record when observed. The displayed wording can change by search, so use source metadata as the intended copy. [Google title link guidance](https://developers.google.com/search/docs/appearance/title-link)
3. Compare complete 28-day periods of equal length and weekday mix before release and after recrawl. Compare the same canonical page, query or predeclared query group, country and device. Segment rows into comparable average-position bands (1–3, 4–10, 11–20, 21+). Show rows moving between bands separately so ranking gains do not get counted as snippet gains. The Search Console UI can export fixed segments. The API can retrieve page, query, country and device in the same rows. [Performance report](https://support.google.com/webmasters/answer/7576553?hl=en) · [Search Analytics API](https://developers.google.com/webmaster-tools/v1/searchanalytics/query)
4. For each matched group, report clicks, impressions, CTR from summed clicks divided by summed impressions, and average position. Use separate query groups for star-rating math, fake-review data, rating impact, rule or removal eligibility, and pricing. Track branded terms separately. Extend both windows if a group has only a few clicks, and retain the sample sizes with the results.
5. Compare qualified organic assessment volume and conversion rate alongside clicks. Keep retired URLs separate when interpreting the historical totals. Progress toward 4–5% overall CTR depends on ranking and query mix as well as the new snippets.
